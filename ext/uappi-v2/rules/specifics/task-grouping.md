## Statement

Group `especifico/` files into **tasks** when they:

- belong to the same module;
- change the same functionality;
- are part of the same flow;
- depend on each other.

Goal: action plan by feature, not only by file.

Generate `02-analise-por-tarefa.md` from `templates/specifics/compare-by-task.md` after (or together with) the per-file analysis when the brief requests `por tarefa` or `ambos`.

## Rationale

Mirrors the legacy comparador task-grouping reference.
